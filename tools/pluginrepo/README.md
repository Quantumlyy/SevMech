Custom [Dalamud](https://github.com/goatcorp/Dalamud) plugin repository for SevMech.

This repository holds only data: the plugin manifests under `plugins/` and the generated
`pluginmaster.json`. Both are written by the release workflow of the plugin's own repository.

## Installation

Add the following custom repository in Dalamud Settings, Experimental tab:

```
https://raw.githubusercontent.com/Quantumlyy/MyDalamudPlugins/main/pluginmaster.json
```

## Plugins

* [SevMech](https://github.com/Quantumlyy/SevMech) - Severe Mechanics: an FFXIV mechanics simulator forked from
  [AnoMech](https://github.com/anomek/AnoMech). Solo practice for ultimates from the safety of your inn.
  It keeps AnoMech's internal name, so only one of the two can be installed at a time.
